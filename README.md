# 🏋️‍♂️ FITLOG - Personal Fitness & Workout Planner

**FITLOG** is a modern, interactive, and fully responsive web application designed to help fitness enthusiasts discover workouts, track daily routines, and save their favorite exercises effortlessly. Built with a fast and intuitive user interface, it ensures a seamless experience across all devices.

---

## 🛠️ Technologies Used

- **Framework:** [Next.js](https://nextjs.org/) (App Router, React 19)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) & [DaisyUI](https://daisyui.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Notifications:** [React Hot Toast](https://react-hot-toast.com/)
- **State Management:** React Context API & `localStorage` persistence

---

## ✨ Key Features

1. **🏋️ Comprehensive Workout Library**  
   Explore a rich collection of exercises with detailed statistics including difficulty level, targeted muscle groups, required equipment, duration, and calories burned.

2. **📅 Daily Workout Planning (Max 5 Lifts)**  
   Add workouts directly to your daily plan. Features a smart daily cap of 5 workouts to ensure a balanced and structured training routine without overexertion.

3. **🔖 Save for Later & Persistent Storage**  
   Bookmark your favorite exercises to access them anytime. All saved workouts and daily plans are automatically synced to local storage so you never lose progress.

4. **✅ Interactive Completion Tracker**  
   Track your progress in real-time by marking exercises as completed. Get immediate feedback on finished workouts with status updates and visual strikes.

5. **📱 Fully Responsive & Optimized UI**  
   Custom-tailored layout supporting mobile, tablet, and desktop views with adaptive navigation counters, compact view controls, and smooth touch-friendly UI components.
